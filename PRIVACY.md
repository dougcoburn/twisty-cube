# Privacy Policy — FaceTurn Cube Solver

FaceTurn Cube Solver runs entirely on your Mac. It does not create an account,
does not include analytics or advertising SDKs, and does not send cube
positions, moves, or any other data to a server.

Solver tables (about 7 MB) are generated on first launch and stored only in
this Mac’s Application Support folder for the app.

Contact: the GitHub issue tracker at https://github.com/dougcoburn/twisty-cube
